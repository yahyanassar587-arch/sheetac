# متجر الشيتات — نسخة Streamlit

نفس فكرة المتجر: العميل يختار الشيت، يحوّل بانستا باي أو محفظة، يرفع سكرين التحويل، وأنت تأكد من لوحة التحكم فيظهر له زرار التحميل.

## التشغيل على جهازك
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## النشر على Streamlit Community Cloud
1. ارفع الفولدر ده على GitHub (الملفات: `streamlit_app.py` و`requirements.txt` و`.streamlit/config.toml` و`.gitignore`).
2. من share.streamlit.io اعمل **New app**، واختار الريبو، والملف الرئيسي `streamlit_app.py`.
3. من **Advanced settings ← Secrets** حط بياناتك:
```toml
ADMIN_PASSWORD = "كلمة-سر-قوية"
STORE_NAME = "اسم متجرك"
INSTAPAY_HANDLE = "yourname@instapay"
WALLET_NUMBER = "01012345678"
WHATSAPP_NUMBER = "201012345678"
```
4. دوس Deploy.

## استخدام الموقع
- لوحة التحكم: زرار "دخول الأدمن" أسفل الصفحة الرئيسية (أو `?admin=1` في آخر الرابط).
- تاب **الشيتات**: ارفع الملف والغلاف والسعر.
- تاب **الطلبات**: شوف سكرين التحويل وأكد أو ارفض بعد ما تتأكد إن الفلوس وصلت.
- العميل بيفضل على صفحة طلبه (بتتحدث لوحدها) ولما تأكد بيظهر له التحميل. رابط صفحة الطلب فيه كود سري، فبيحتفظ بيه.

## ⚠️ مهم: التخزين على Streamlit Cloud مؤقت
الملفات والطلبات بتتخزن في فولدر `data/` على سيرفر Streamlit، وبتتمسح لما التطبيق يتعمله ريستارت أو إعادة نشر أو بعد فترة خمول.
- نزّل **نسخة احتياطية** من تاب "نسخة احتياطية" بشكل منتظم، وارجعها من نفس التاب بعد أي ريستارت.
- للاستخدام الجاد بفلوس حقيقية، الأفضل استضافة بتحفظ الملفات (زي PythonAnywhere بنسخة Flask) أو ربط التطبيق بتخزين خارجي.

## ملاحظات
- لو الريبو Public ما تحطش بيانات حساسة فيه؛ استخدم Secrets بس.
- كلمة السر الافتراضية `admin123` لازم تتغيّر.
